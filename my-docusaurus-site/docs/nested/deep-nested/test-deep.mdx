## 验证要点

1. **路径转换**：原路径 `/docs/nested/deep-nested/test-deep` 
2. **新文件名**：`docs-nested-deep-nested-test-deep.html`
3. **链接更新**：所有相对链接应该被正确更新
4. **资源路径**：CSS、JS、图片等资源路径应该正确指向根目录
